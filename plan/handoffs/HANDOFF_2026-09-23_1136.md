## Decisions locked in this session

- **Upload types:** text/code/JSON (same `EXT` list as model tools) plus PNG, JPEG, GIF, WebP, PDF. No SVG (script risk).
- **Limits:** text 200 KB, images/PDFs 8 MB.
- **Replace without asking**, keep a backup in `data/backups`.
- **Models do not read images or PDFs.** They only appear on the Files page.
- **Chat + saves to the project** (user chose this over sending file content in the message). Folder is fixed: `uploads/`.
- In the **Mother** project, uploads land in the repo folder (its `project_path` is the repo root).
